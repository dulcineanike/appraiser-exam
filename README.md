# 不動產估價師歷屆試題・全真模擬考卷與考友社群系統

> 🏛️ **收錄民國 91～115 年國家考試 638 題**  
> 專為專門職業及技術人員高等考試「不動產估價師」考生量身打造的極簡、嚴謹、高分刷題與考友互助平台。

---

## 🌟 核心特色功能

1. **🤖 AI 嚴謹精煉擬答（榜首級標準）**
   - 依據全國法規資料庫現行最新條文、不動產估價師公會第 1～8 號專業公報與司法實務（最高法院民事大法庭裁定、憲法法庭判決、大法官釋字）嚴密校準。
   - 純數理模型（經濟學 DW 四象限、Alonso 競租模型、NPV/IRR 財務計算）提供標準考場作圖指南與公式推導步驟。
   - 國文作文題純淨呈現立意剖析，絕不硬塞無關法條。

2. **🎖️ 會員制度、貢獻積分與五大榮譽稱號**
   - 🐣 **Lv.1 估價學徒**（0～49 pt）：初入地政與三大估價法門徑之新進考生。
   - 📜 **Lv.2 助理估價員**（50～199 pt）：熟習技術規則條文，開始提出法規關鍵要件。
   - ⚖️ **Lv.3 執業估價師**（200～499 pt）：具備獨立破題與三大估價法精算能力。
   - 🏆 **Lv.4 資深合夥估價師**（500～999 pt）：融會貫通公報、裁判與經濟學圖解。
   - 👑 **Lv.5 榜首大宗師**（1,000+ pt）：全科考點精準洞悉，考友社群頂級榮譽標竿。

3. **👥 考友社群筆記與點讚互助**
   - 每題開放發表社群解題心得（+20 積分），獲得他人按讚（+5 積分）。
   - 支援「+引用至私房筆記」，快速整合至個人手寫草稿紙。
   - 內建考友貢獻榮譽榜（Leaderboard）與稱號圖鑑。

4. **📝 全真考卷作答室**
   - 隨機組卷（自訂考科、題數、年份範圍）。
   - 倒計時作答時鐘與「盲測模式」（隱藏出題年份，交卷才揭曉）。
   - 友善 A4 排版列印（支援雙面列印與橫式排版）與純文字檔匯出。

5. **🗺️ 73 項法規考題地圖**
   - 快速索引技術規則、民法物權編、土地徵收條例、都更條例、估價公報之歷屆考題出題頻率。

## 🚀 GitHub Pages 快速上架與瀏覽

本專案已配置自動化部署（GitHub Actions）：
1. 將本專案 Push 至 GitHub 倉庫的 `main` 分支。
2. 進入倉庫的 **Settings** $\to$ **Pages**。
3. 在 **Build and deployment** 下方的 **Source** 選擇 **GitHub Actions**（或選擇 **Deploy from a branch** $\to$ `main` / root）。
4. 等待約 1 分鐘，即可透過 `https://<你的GitHub帳號>.github.io/<倉庫名稱>/` 在手機或電腦上開啟使用！

## ☁️ 啟用全台考友雲端即時同步（可選）

本系統預設以瀏覽器本機儲存（LocalStorage）運作，免設定即開即用。若希望讓所有造訪網站的考生即時看到彼此的社群筆記與排行榜：
1. 前往 [Supabase](https://supabase.com) 免費註冊並建立專案。
2. 在 Supabase 後台的 **SQL Editor** 貼上並執行本專案根目錄的 `supabase_schema.sql`。
3. 將專案中的 `Project URL` 與 `anon public key` 填入 `web/supabase_config.js`。
4. Push 至 GitHub，網站即刻升級為全台考友即時雲端互助平台！
